Active Directory & Group Policy Lab | Windows Server 2022

## Associated with
Leave this unassociated with an employer. It is a self-directed technical lab.

## Description
Designed and implemented a Windows Server 2022 Active Directory lab in a virtualized environment. Established the `corp.lab` domain, departmental OUs and security groups, SMB file sharing, department drive mappings, domain password and account-lockout settings, and workstation restrictions through Group Policy. Captured HR domain logon, H: drive mapping, Control Panel restriction, and CD/DVD access-denied evidence. Includes an architecture diagram, technical report, implementation runbook, screenshots, and a security remediation review. Some controls remain pending additional client-side validation.
