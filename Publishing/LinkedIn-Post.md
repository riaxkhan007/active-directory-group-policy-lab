# LinkedIn project announcement

I recently completed a hands-on Windows Server 2022 Active Directory and Group Policy lab focused on building and managing a small departmental domain environment.

The project covered:

- Active Directory Domain Services and DNS for `corp.lab`
- Departmental Organizational Units and security groups for HR, Finance, IT, and Management
- SMB file sharing with department folders and mapped network drives
- Domain password and account-lockout policies
- Workstation restrictions through Group Policy
- Client-side validation using an HR domain account

I captured the HR user logon, H: drive mapping, a Control Panel restriction message, and CD/DVD access denial. I also reviewed the configuration for security improvements, including installer privilege policy, password length, share permissions, and GPO scope.

This was a self-directed lab built to strengthen practical skills in Windows Server administration, Active Directory, Group Policy, and endpoint configuration. I am continuing to refine the security baseline and complete the remaining client-side test cases.
